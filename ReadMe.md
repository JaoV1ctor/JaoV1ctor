## 🤖 Sobre Mim

Focado na convergência entre **Inteligência Artificial**, **Agentes Autônomos** e **Automação de Sistemas de Alta Fidelidade**. Atualmente, projeto ecossistemas digitais utilizando metodologias modernas de **Vibe Coding** — transformando lógica corporativa complexa em interfaces fluidas, automatizadas e inteligentes.

* 🧠 **Visão:** Otimizar e escalar a eficiência de negócios modernos através de agentes autônomos e hiperautomação.
* ⚡ **Expertise:** Arquitetura de Workflows escaláveis, Integração de LLMs de ponta e Engenharia de Prompt avançada.
* 🤝 **Mindset:** Resolução ágil de problemas, entrega ágil de valor e código focado em performance.
